# 班级座位助手

面向初中老师的本地排座工具。打开班级后直接看到教室，支持快速排座、局部调整、规则检查、发布、投影和打印。

## 启动

需要 Node.js 22。首次启动：

```bash
./start.sh
```

或手动运行：

```bash
npm ci
npm run dev
```

在浏览器打开终端显示的本地地址（默认 `http://localhost:5173`）。首次进入会看到初始化引导：创建班级、导入名单、确认教室容量；也可以先体验示例班级。

## 常用流程

1. 在初始化引导中创建班级，粘贴学生姓名（每行一个，可在姓名后写“男”或“女”），或导入 `.xlsx` / `.csv` 名单。表格有“姓名”“性别”列时会自动读取；未填写的性别保持未知，可在“学生与规则”页编辑性别和是否戴眼镜。
2. “编辑教室”进入可视化编辑器。每排可分别增减桌子、切换单人 / 双人桌，也能一键给每排添加一列；点击教室图上的座位可停用或启用，还可设置门窗位置。编辑器只显示可用座位和人数容量，不显示学生姓名。停用座位会从正常座位图中消失，原座学生进入左侧红色的待安排列表，可拖到空位或依次点击学生和空位；操作支持撤销。
3. 在“学生与规则”页查看每人的座位需求与学生关系；展开学生后可直接新增、调整优先级或删除规则，同时查看轮换轨迹。可多选学生后批量删除。
4. 点击“帮我排”，选择目标、核对规则，也可选择尽量同性或异性同桌。该偏好只对已标注性别的学生生效，且必要规则和锁定位置优先。不选性别偏好时可比较 3 个优化方案与 2 个规律轮换方案；选择后可比较 3 个优化方案。当前草稿与选中方案并排显示，蓝色桌椅标出座位变化。点击“使用这个方案”后仍是草稿，可继续拖动或点击“换座”微调。
5. 点击“发布座位”检查人数、变化和规则问题，填写开始使用日期、学期周次和备注，可立即启用或保存为待启用版本。发布后可用“投影视图”引导换座，或打印学生版 / 教师版座位表。
6. “历史版本”页可任选两个正式版本或工作草稿并排对比；旧版可复制到草稿，当前正式版不会被覆盖。首页“对比上一版”直接打开对应的左右对照。“座位轮换”页可按学生、轮次及日期筛选，教室图仅显示选中学生的姓名、序号、启用日期和实际移动箭头；座位不变时不画箭头。箭头绘制在桌椅上层，便于辨认移动方向。

按住 Ctrl / Cmd 点击可多选学生并批量锁定。`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做，`/` 搜索学生，`L` 锁定选中学生，`Esc` 取消选择。

## 数据与使用边界

- 草稿和发布历史自动保存在当前浏览器的本机存储中。通过侧栏“备份数据”下载 JSON；换设备时可导入备份。清理浏览器数据可能删除本地记录。
- “发布”会在本机保存正式座位并用于投影和打印；当前版本没有账户、跨设备同步或向学生发送通知。
- 自然语言入口只识别明确姓名与“分开 / 不同桌 / 不动 / 锁定 / 前三排”等表达。系统会先展示识别结果，老师确认后才用于生成。
- 自动排座会保留锁定与近期手工调整的位置；必要规则无法满足时会显示问题，老师可以调整规则或明确选择本轮放宽。
- 优化方案先保留固定位置，再尝试修复必要规则冲突，最后用固定种子的多次座位交换比较规则、变化人数、前后轮换和同桌历史；同一输入可复现。规律方案按列循环前移，单数列前移一排、双数列前移两排等；固定学生不动。如果规律轮换与必要规则冲突，系统会尽量用少量交换修正并说明微调人数；仍无法满足时会显示冲突并禁止采用。

## 验证

```bash
npm run test
npm run build
```

测试覆盖锁定位置、必要规则、容量不足、局部调整、待安排学生手工入座、轮换历史、本轮规则、少动方案、混合桌型与规律轮换。前端使用 React、TypeScript 与 Vite；排座计算在浏览器本机完成，无服务端依赖。
